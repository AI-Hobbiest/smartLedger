Smart Ledger Preview — Development Notice

This is a development preview. Do not enter real financial information.

Data handling in this preview

  • Sample transactions, trips and budgets are stored in the current browser's local storage on this device.
  • This preview does not connect to OneDrive or a cloud database and does not synchronise between devices.
  • Development backup exports are plain JSON and are not encrypted. Use synthetic test data only.
  • The site does not require a Microsoft sign-in or an application account.

Before real-world use

A production storage provider, client-side encryption, secure authentication, backup/recovery, cross-device conflict handling and a security review must be implemented and tested before real financial records are entered.
