Privacy Notice

Prototype notice · Last updated 13 November 2026

Prototype boundary: Smart Ledger is currently a browser-based test application. Entries are stored in this browser only and are not synced to OneDrive or a cloud ledger.

1. Information stored in this browser

Transactions created in the Conversation Test and Entry Test prototypes are stored in your browser's local storage on this device. The current prototype does not upload saved transaction rows, account balances or locally calculated report totals to the Smart Ledger AI service. Clearing browser site data may remove these local test entries. Do not use this prototype as the sole record of real financial activity.

2. Smart Ledger AI and Groq

When you use AI-powered conversation features, the application sends the message you submit and a limited history of recent user messages to the Smart Ledger backend hosted on Cloudflare. The backend forwards the information needed for language interpretation to Groq. A small structured report context (such as the requested date range and filters) may also be sent. Saved ledger rows, balances and locally calculated report totals are not included in that AI request.

Groq processes these prompts to return a structured interpretation. Its handling, retention and use of submitted information are governed by Groq's Privacy Policy and applicable service terms. Do not submit sensitive financial, payment-card or identity information in this prototype.

3. Cloudflare Turnstile security checks

Smart Ledger uses Cloudflare Turnstile to help distinguish people from automated or malicious requests and protect the AI endpoint. Turnstile runs in the browser when an AI message is submitted. With Invisible mode enabled, the verification runs without displaying a widget during normal use.

According to Cloudflare, Turnstile processes technical signals that can include the visitor's IP address, TLS fingerprint, User-Agent header, sitekey and associated origin. Cloudflare describes its purpose as bot detection and protection of the website. Cloudflare's processing and privacy practices are explained in its Turnstile Privacy Addendum, which forms part of the privacy information for this feature.

4. Data sharing and security

Smart Ledger does not sell your personal information. Information is shared with Cloudflare for request security and with Groq when you submit an AI interpretation request, as described above. The AI endpoint uses server-side Turnstile token validation and request protections. No security measure can guarantee absolute protection.

5. Your choices

You can use the manual Entry Test without submitting prompts to the AI provider. You can stop using the AI conversation at any time. You can remove locally stored prototype entries by using the application's clear-data controls where available, or by clearing this site's browser storage. Removing browser data does not remove information already processed by Cloudflare or Groq; consult their respective privacy notices for those services.

6. Changes to this notice

This notice describes the current prototype. It must be reviewed and updated before Smart Ledger is expanded to cloud accounts, family sharing, OneDrive integration or production financial records.
