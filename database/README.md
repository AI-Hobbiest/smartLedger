# Database templates

The blank Excel schema template is maintained as `SmartLedger_DB_Template_v1.1.xlsx` (7 sheets: Transactions, Users, Trips, TripMembers, Budgets, Settings and Lists). Upload the blank workbook here. Never replace it with a workbook containing live family financial records.

The schema and field definitions are documented in `../docs/DB-Schema-v1.1.md`.
